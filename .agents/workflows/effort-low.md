# /effort-low — Fire & Forget

> Act immediately. Don't overthink. Ship fast.

Announce on activation: `⚡ Effort: low`

---

## Directives

- **Research**: Max 1 file read. Use only what's already in context. Skip KI summaries.
- **Verbosity**: Conclusion-only. 1-3 lines max. No reasoning chain. No "here's what I did".
- **Planning**: Never create plans. Never create implementation_plan.md. Just execute.
- **Verification**: Trust the edit. No test runs. No lint. No build checks.
- **Research breadth**: Immediate context only. No grep. No web search. No doc lookups.

---

## When to Use

- Typo fixes
- One-liner changes
- Quick questions with obvious answers
- Formatting and whitespace
- "Just do it" tasks
- Renaming variables or files
