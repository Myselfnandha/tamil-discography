# /effort-ultra — Leave Nothing Unchecked

> Exhaustive analysis. Document everything. Zero blind spots.

Announce on activation: `⚡ Effort: ultra`

---

## Directives

- **Research**: Read every related file and doc. Trace every caller, every dependency. Map the full dependency graph.
- **Verbosity**: Detailed report with alternatives, risks, edge cases, and rollback strategies. Artifact-level documentation.
- **Planning**: Always create implementation_plan.md + walkthrough.md. Request user review before executing.
- **Verification**: Full test suite + lint + build + manual checklist. Verify every assumption.
- **Research breadth**: KI + grep + docs + web + cross-reference everything. Verify unfamiliar APIs via REPL/docs. Leave no stone unturned.

---

## When to Use

- Production deployments
- Security audits and `/ifixai` runs
- Breaking changes across consumers
- Mission-critical systems
- Data migration with no rollback
- Compliance and regulatory work
