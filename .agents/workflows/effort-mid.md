# /effort-mid — Balanced

> Research enough to be right, then act. Don't over-analyze.

Announce on activation: `⚡ Effort: mid`

---

## Directives

- **Research**: 2-5 file reads. Check KI summaries if titles match. Grep for related code.
- **Verbosity**: Conclusion-first + key reasoning. 3-8 lines. State uncertainty if any.
- **Planning**: Plan only for multi-file architectural changes. Skip for everything else.
- **Verification**: Run tests if a test suite exists. Report pass/fail. Don't add extra checks.
- **Research breadth**: KI summaries + grep relevant files. No web search unless stuck.

---

## When to Use

- Standard coding tasks
- Bug fixes with clear reproduction
- Feature additions to existing modules
- Refactors within a single component
- Most everyday work
