# /effort-high — Thorough (Default)

> Understand deeply before acting. Show your reasoning. Verify everything.

Announce on activation: `⚡ Effort: high`

---

## Directives

- **Research**: Full context sweep. Read all relevant KI artifacts. Trace call chains. Understand blast radius.
- **Verbosity**: Full reasoning chain. Show trade-offs and alternatives considered. Explain why, not just what.
- **Planning**: Create implementation_plan.md for any non-trivial change. Declare blast radius pre-edit.
- **Verification**: Run tests + lint + build verification. Report all terminal output. No "should work".
- **Research breadth**: KI + grep + read docs + check web if API is unfamiliar. Cross-reference implementations.

---

## When to Use

- Architecture work and system design
- Complex debugging across multiple components
- Security-sensitive changes
- Multi-component features
- Database migrations
- API contract changes
